# **App Name**: Unity Codex

## Core Features:

- Snippet Display: Display Unity C# code snippets with syntax highlighting.
- Snippet Explanation: Provide a brief explanation of each code snippet's purpose.
- Code Copy: Enable users to easily copy code snippets with a 'Copy Code' button.
- Markdown Support: Allow content creation using Markdown for easy posting.
- Light/Dark Mode Toggle: Implement a toggle for switching between light and dark modes.
- Dynamic Content Loading: Automatically load snippet data from a JSON file or Markdown files.
- Snippet Tagging: Organize snippets with tags (e.g., Input, UI, AI, Gameplay).

## Style Guidelines:

- Dark background (#1E1E1E) for a developer-friendly feel.
- Primary color: Neon Green (#32CD32) for code highlighting accents.
- Accent color: Electric Violet (#8A2BE2) to complement the green, suggesting high technology.
- Monospace font: 'Source Code Pro' for a coding documentation aesthetic. 
- Note: currently only Google Fonts are supported.
- Minimalist layout with a navigation bar and card-based snippet display.
- Simple icons for categories and the copy code button.
- Subtle transition animations for the light/dark mode toggle.
